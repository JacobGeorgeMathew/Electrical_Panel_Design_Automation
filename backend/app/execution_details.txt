1. Install system dependencies on Arch Linux

sudo pacman -Syu
sudo pacman -S --needed git nodejs npm python python-pip python-virtualenv

Verify:

node --version
npm --version
python --version

Node.js 18+ and Python 3.10+ should work.

2. Clone and enter the project

git clone https://github.com/nithin1018/MP-Prototype-1.git
cd MP-Prototype-1

3. Set up the FastAPI backend

The repository currently does not contain a  requirements.txt , so install the backend dependencies manually:

cd backend

python -m venv .venv
source .venv/bin/activate

python -m pip install --upgrade pip
python -m pip install fastapi "uvicorn[standard]" pydantic shapely networkx ortools pytest

Start the backend:

python -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000

The API will be available at:

• API: http://127.0.0.1:8000
• Health check: http://127.0.0.1:8000/health
• Swagger documentation: http://127.0.0.1:8000/docs

Keep this terminal running.

To run backend tests, use another terminal:

cd MP-Prototype-1/backend
source .venv/bin/activate
pytest

4. Set up and run the React frontend

Open a second terminal:

cd MP-Prototype-1/frontend
npm ci
npm run dev

The frontend will be available at:

http://localhost:3000

The Vite configuration already proxies  /api  requests to:

http://localhost:8000

Therefore, both services should be running as follows:

┌─────────────────┬─────────────────────────────────────────────────────┬───────────────────────┐
│ Service         │ Command                                             │ URL                   │
├─────────────────┼─────────────────────────────────────────────────────┼───────────────────────┤
│ FastAPI backend │ python -m uvicorn app.main:app --reload --port 8000 │ http://localhost:8000 │
├─────────────────┼─────────────────────────────────────────────────────┼───────────────────────┤
│ React frontend  │ npm run dev                                         │ http://localhost:3000 │
└─────────────────┴─────────────────────────────────────────────────────┴───────────────────────┘

5. Production frontend build

cd frontend
npm run build
npm run preview

The frontend source uses the backend proxy configured in  frontend/vite.config.ts , so start the backend before using the application.
